# BusyBox Wrapper Suite

This project scaffolds a modular, installable, and validated BusyBox wrapper for Android/Termux environments.

## 🏗️ Installers
- Builds and signs the BusyBox wrapper APK
- Installs the signed APK and validates install path
- Installs BusyBox binary and exports dashboard
- Installs BusyBox binary and exports dashboard

## 🧪 Validators
- Validates APK install and dashboard presence
- Validates BusyBox module symlinks and applet count

## 🐚 Wrappers
- Launches BusyBox with optional applet test loop
- Launches BusyBox with optional applet test loop
